# Code Availability

The custom implementation for the manuscript is released as source code at:

<https://github.com/crack1111-svg/crack>

The release is intended to contain the model implementation, training and inference entry points, evaluation scripts, configuration options, and reproducibility documentation. Dataset images, annotations, and pretrained weights are not redistributed by default because their availability and redistribution rights are governed by the original dataset and model providers.

For the manuscript-matching version, create a versioned GitHub release and archive that release in Zenodo or another recognised DOI-assigning repository. The permanent DOI and release tag must be inserted here before submitting the revision:

```text
Version: to be assigned
DOI: to be assigned
```

The repository documentation specifies the expected dataset structure and the commands for training, inference, and evaluation. Any dataset-specific split files, configuration files, or checkpoints used to generate reported results should be attached to the corresponding versioned release whenever redistribution is permitted.
